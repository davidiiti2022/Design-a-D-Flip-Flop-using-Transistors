# Design-a-D-Flip-Flop-using-Transistors


Duration: Jan 2025 – Mar 2025
Domain: Digital Electronics / VLSI Fundamentals / Analog Electronics
Technology: Discrete BJT Transistors
---

## 📌 Project Overview

This project focuses on the design and implementation of a **D Flip-Flop** using discrete **BJT (Bipolar Junction Transistor)** components. Instead of using pre-built ICs, the flip-flop is constructed from transistor-level logic gates and feedback networks to demonstrate the internal working of sequential circuits. The circuit captures the input data on the active clock edge and stores it until the next triggering event.

---

## 🎯 Objectives

- Design a D Flip-Flop using discrete BJT transistors.
- Understand transistor-level implementation of sequential circuits.
- Demonstrate edge-triggered data storage.
- Analyze the role of feedback in maintaining stored data.
- Verify correct operation using different input and clock combinations.

## ⚙️ Working Principle

- The **D (Data) input** represents the value to be stored.
- On the active clock edge, the flip-flop samples the input data.
- Internal transistor-based logic transfers the input to the output.
- Feedback paths maintain the stored logic state until the next clock pulse.
- Changes in the D input have no effect until the next triggering clock edge.
